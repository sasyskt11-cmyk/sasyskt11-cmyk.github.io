# ROOTS NUTRITION — Official Brand Website

科学的根拠を重視したスポーツ栄養ブランド「ROOTS NUTRITION」の公式ブランドサイト（開発中）。
静的サイト（HTML / CSS / JavaScript、フレームワーク不使用）。

## 構成
- `index.html` — HERO / BRAND / PRODUCTS / SCIENCE & DEVELOPMENT / OUR STORY / JOURNAL / CONTACT
- `style.css` — デザイン（ブラック×深緑×ゴールド×オフホワイト、レスポンシブ対応）
- `script.js` — スクロールアニメーション、パララックス、モバイルメニュー
- `assets/` — ロゴ・パッケージ・キービジュアル等のブランド素材

## 公開
GitHub Pages（無料）での公開を想定。リポジトリの Settings → Pages で
「Deploy from a branch / main / root」を選ぶと公開されます。

## ローカル確認
`python3 -m http.server 8123` で起動し、http://localhost:8123/ を開く。
